# Satchel

A unified bag window for World of Warcraft: Forever. The backpack, your four bags and the reagent bag show as one grid, with search, sort, free slots and gold.

## Install

Copy or symlink this folder into `World of Warcraft/_forever_/Interface/AddOns/Satchel`.

## Use

Open your bags as usual (B, the bag bar, vendors). Drag the title bar to move the window.

| Command | Does |
| --- | --- |
| `/satchel` | Toggle the window |
| `/satchel cols <6-30>` | Slots per row (default 10) |
| `/satchel scale <0.5-2>` | Window scale |
| `/satchel reset` | Move the window back to the bottom right |
